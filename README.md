# 留灯小店

一个温暖的中文打字练习网站。

- 剧情练习：选择故事，一边打字一边看剧情，逐句自动推进。
- 自由文本练习：粘贴文字或导入 TXT、Markdown，独立练习自己的文章和小说。
- 每句显示字速、正确率和用时；从首次输入开始，到正确完成该句停止计时。
- 文字内容和练习进度保存在当前浏览器中。

## 使用

开启 GitHub Pages 后，在仓库 Settings → Pages 查看发布网址。学生无需 GitHub 或 ChatGPT 账号。

也可以下载 `index.html`，在电脑浏览器中打开，离线练习。

## 发布

在 Settings → Pages 中选择 Deploy from a branch，使用 main 分支和 /(root) 目录。

这是无外部依赖的静态网站，无需安装依赖或构建。仓库根目录的 `.nojekyll` 用于直接发布。
